# Superpowers: Agentic Framework & Software Engineering Methodology

`superpowers` is an elite agentic workflow framework and software development methodology designed to orchestrate high-performance AI agents.

## 1. Core Principles & Philosophy

1. **Specification & Plan First**: Never write production code without an explicit, verifiable design document and architecture specification.
2. **Empirical Evidence-Driven Debugging**: Diagnostics must be backed strictly by raw log traces, terminal outputs, and empirical test results — no guesswork or superficial symptom patches.
3. **Test-Driven Verification (TDD)**: Every feature or fix must be validated with automated unit/integration tests or concrete execution commands before declaring success.
4. **Anti-Slop Visual & Engineering Discipline**: Deliver agency-grade ($150k+ tier) user interfaces, modular decoupled codebases, and zero lazy placeholders.
5. **Continuous Verification Loop**: Edits are complete ONLY when execution commands pass cleanly without errors.

## 2. Methodology Workflows

### A. Feature Architecture & Scaffolding
- Define data schemas, API contracts, and component interfaces upfront.
- Establish clean directory structures, design tokens, and modular separation of concerns.

### B. Execution & Refactoring Protocols
- Execute code edits in tight atomic chunks.
- Respect linting, type safety, and existing API contracts across invocation sites.

### C. Automated Testing & Verification
- Execute unit/integration test suites.
- For UI applications, verify layout responsiveness, visual hierarchy, and micro-animations.

## 3. Universal Quality Checklist
- [ ] Requirements fully analyzed and documented
- [ ] No hardcoded brittle logic or magic numbers
- [ ] Empirical log verification before diagnosing errors
- [ ] Complete, unabridged implementation without truncation or placeholders
- [ ] Verified build and execution status
